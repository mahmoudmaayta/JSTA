You are a senior full-stack engineer. Implement an Electronic Commitment (Complaints) Form (Arabic UI, RTL) with e-consent (checkbox, no wet signature). Integrate with existing auth, DB, and APIs. Do not duplicate existing forms or code—extend current structure.

SCOPE

One form: Electronic Commitment (Complaints).

Vertical “A4-style” layout (stacked sections), no horizontal scrolling.

Arabic labels (RTL). Keep i18n keys so English can be added later.

Submit to existing API or create POST /api/forms/commitment.

Complaints (repeatable rows; add/remove)

complaintNumber (text, required) — رقم الشكوى

authority (select: جمعية/وزارة/أخرى, required) — الجهة

notifiedAt (date, required) — تاريخ الإشعار

summary (textarea, max 200 chars, optional) — ملخص قصير

proposedAction (textarea, optional) — إجراء مقترح

Commitment Text (static) + e-consent

Render the Arabic commitment text:

“أوافق على بذل أقصى جهد لتسوية الشكوى/الشكاوى المقدَّمة إلى الجمعية/الوزارة بحق المكتب، وتزويد الجهة المختصة بما يثبت ذلك خلال مدة أقصاها 30 يومًا من تاريخ الإشعار، وتحت طائلة الإحالة إلى المجلس التأديبي في حال وجود شكاوى مُحِقّة بقرار من لجنة الشكاوى.”

consentAccepted (checkbox, required) — أوافق على التعهُّد…

Auto-captured (read-only display)

actorName (from session)

submittedAt (server time)

ip, userAgent (server-side capture)

Complaints: if any row exists → enforce required fields in that row. Allow 0..N rows (min 1 row recommended—configurable).

summary ≤ 200 chars.

consentAccepted must be true.

Localized Arabic error messages under fields.

API CONTRACT
Endpoint (create if missing): POST /api/forms/commitment
Request JSON:

{
  "officeId": "<uuid-or-code>",
  "officeName": "شركة السلام",
  "licenseNo": "JSTA-2026-7789",
  "contact": { "name": "أحمد", "email": "ops@agency.jo", "mobile": "+9627..." },
  "complaints": [
    {
      "complaintNumber": "C-2026-001",
      "authority": "الجمعية",
      "notifiedAt": "2026-01-15",
      "summary": "تأخير في الرد.",
      "proposedAction": "الرد خلال 24 ساعة."
    }
  ],
  "consent": { "type": "COMPLAINT_COMMITMENT", "accepted": true }
}


Response JSON:

Success: { "ok": true, "data": { "commitmentId": "<id>" } }

Error: { "ok": false, "error": { "code": "VALIDATION_ERROR", "message": "..." } }

(Optional) Trigger notification: email/WhatsApp “commitment received”.
